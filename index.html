Install on your TV

  1. Get Downloader

    On your Android TV or Google TV, install Downloader by AFTVnews from the Google Play Store.

  2. Enter the Downloader code

    Open Downloader, enter 4821603 in the URL field, and select Go.

  3. Install StreamSeat

    When the download finishes, select Install. If Android asks, allow Downloader to install unknown apps, then return to the installer. Open StreamSeat from your apps.

When upgrading from 1.0.0, StreamSeat installs as a separate app. Sign in again after installing.
